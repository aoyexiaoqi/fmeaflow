# 检查项说明与局限

## 检查项

| 编号 | 检查 | 严重度 |
|---|---|---|
| C1 | PFMEA 失效模式所在工序在控制计划中无任何控制行 | S≥9 为高，否则中 |
| C2a | PFMEA 的预防/探测控制未出现在控制计划对应工序的控制方法中 | 中（S≥9 且缺探测控制为高） |
| C2b | 同一控制在 PFMEA 与控制计划中预防/探测分类不一致 | 中 |
| C3 | 特殊特性标记只在其中一份文件中出现 | 高 |
| C4 | S/O/D 已填写但 AP 为空 | S≥9 为高，否则中 |
| C5 | 控制计划行的工序在 PFMEA 中不存在 | 低 |
| C6 | 同一工序号在两份文件中工序名称不一致（仍按工序号关联） | 低 |

每个问题都标注来源文件、工作表与**确切行号**（表头为第 1 行），方便回溯原表。

退出码：0 = 无问题，2 = 有问题，1 = 输入/使用错误。

## 硬性边界

- 本工具**不评定、不批准 AP**，不批准 PFMEA 或控制计划；只标记问题、
  给出工程师复核建议。AP 评定必须由工程师按 AIAG-VDA 手册人工完成。
- 规则为确定性文本匹配，不含 AI 推断；措施文字写法差异过大时可能漏报或误报，
  建议两份文件统一措施措辞，或用列名映射与规范模板对齐。

## 已知局限（V1）

- 一个工序一行失效模式的扁平表结构；合并单元格需先在 Excel 中填充展开。
- 控制措施按文本匹配，分行/同义改写（如「首件检验」vs「首件确认」）可能被判为缺失。
- 特殊特性只按显式标记列核对，不根据 S 值推断特殊特性。
- 仅支持 .xlsx / .csv；.xls 老格式请先另存为 .xlsx。
- 工序关联以工序号为主键：两份文件的工序号编码体系必须一致。
